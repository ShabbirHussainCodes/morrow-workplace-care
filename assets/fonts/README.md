# Fonts

The site serves its own fonts, so no visit contacts a font host.

| File | Font | Source | Licence |
|---|---|---|---|
| `inter-latin-wght-normal.woff2` | Inter, variable weight, Latin subset | `@fontsource-variable/inter` 5.3.0 | SIL Open Font License 1.1 (`LICENSE-Inter.txt`) |
| `fraunces-latin-opsz-normal.woff2` | Fraunces, variable weight and optical size, Latin subset | `@fontsource-variable/fraunces` 5.3.0 | SIL Open Font License 1.1 (`LICENSE-Fraunces.txt`) |

The files were copied unchanged from those npm packages. The packages are not dependencies of
this project. To update a font, download the new package version, copy the file, and update
the version in this table.
